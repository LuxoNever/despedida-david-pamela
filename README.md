# Invitación Digital — David & Pamela

Una invitación digital creada con cariño para compartir una ocasión especial: la cena de despedida de David y Pamela.

Este sitio reúne nuestros recuerdos, los detalles del encuentro y una forma sencilla de confirmar la asistencia.

Diseñado como una experiencia interactiva, con fotografías, animaciones y una presentación adaptable a dispositivos móviles.

**Lo bonito es estar juntos.**
